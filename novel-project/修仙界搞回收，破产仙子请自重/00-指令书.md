## 2. 题材 / 平台 / 读者

## 3. 一句话钩子（logline）
> 重生回修仙界最底层的杂役顾央，觉醒了「回收十倍返还」系统——别人眼里一文不值的废丹、破法宝、烂灵材，经他回收必得十倍回报；前世欠他人情的清冷仙子如今破产落魄，拎着家底硬蹭他的回收摊，一路误会横生、扮猪吃虎，把收破烂的摊子做成了仙界第一商号。

## 4. 期待感公式
熟悉类型（修仙收破烂逆袭 + 系统返还） + 极致反差（高冷破产仙子 vs 底层收破烂杂役；人人嫌弃的破烂 vs 回收即得仙品） = 期待感

## 5. 核心爽点循环（可无限复用）
| 环节 | 机制 |
|---|---|
| 收 | 捡/收别人不要、嫌弃、扔掉的废品（越破烂越没人要，返还成色越逆天） |
| 反 | 触发「回收十倍返还」：废丹→仙丹、碎剑→神兵、破阵盘→古宝 |
| 藏 | 闷声发财、装穷、装不懂（扮猪吃虎），不暴露系统 |
| 打 | 被轻视→随手用"破烂"翻盘打脸；反派聪明、有脑，主角靠信息差/规则碾压 |
| 笑 | 破产仙子误会主角是隐藏大佬，各种没下限蹭资源，被"请自重"打回 |

## 6. 主角 + 核心冲突
- **主角一句话**：重生归来的底层杂役顾央，靠"回收十倍返还"系统，在修仙界把收破烂做成最大生意。
- **核心冲突**：
  - 表层：破产仙子洛倾雪赖上主角，主角只想闷声发财、不想被拖下水；
  - 底层（第三幕收）：回收系统的真正来源——上古"回收仙尊"陨落之谜，与前世坑死顾央的幕后黑手。

## 7. 禁区（红线，违反即返工）
- 不写**圣母 / 憋屈 / 虐主**；不写**绿帽 / 牛头人 / 女角色被侮辱**。
- 反派**不降智**（把反派换成聪明人，剧情仍成立）。
- 金手指**不向任何人泄露**（说漏 = 惩罚），不写"系统术语被外人听懂"。
- 男主**不猥琐、不油腻**：对仙子的喜剧边界靠"请自重"的克制，不靠下流段子。
- 不写**文青金句 / 说教句 / 上帝视角**；章末要钩子不要升华。
