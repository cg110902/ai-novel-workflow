# 02 · 人物卡（活文档）

> 铁律：人物开口必须像本人，删掉名字也能听出是谁在说话。
> 喜剧另加：每人一个"反差点"（人设 vs 实际），反差才是笑点发动机。

## 主角 顾央
- **身份 / 前世今世**：前世 = 散修鉴宝师，靠半卷《废宝录》点废成宝，临了被"老友"背后一刀、为夺书被围杀；今生 = 青云宗外门杂役（同名同姓）。
- **性格 / 欲望 / 缺陷**：苟、财迷、嘴毒心软；欲望 = 闷声发财 + 查清前世被坑的真相；缺陷 = 见财眼开、嘴硬、护短。
- **语言指纹**：「这破」「血亏」「回本了」「仙子请自重」「闷声发大财」
- **金手指**：回收返还系统（每日次数随境界涨）。
- **反差点**：一身补丁杂役服，实则眼毒手辣、身怀上古灵宝。

## 主反派（第一卷前台小反派；幕后黑手缓揭）
- **王管事**：青云宗外门管事，克扣杂役例钱、狗仗人势。动机 = 贪财。指纹：「狗东西」「规矩」「克扣」。反差点：欺软怕硬，见风就转。

## 女主 洛倾雪
- **身份**：前玄女宫圣女，玄女宫倾覆后背负巨债流落坊市。
- **性格 / 欲望 / 缺陷**：表面高冷端庄，实际为灵石没下限；欲望 = 还债 + 重建玄女宫；缺陷 = 死要面子、嘴硬、认死理。
- **语言指纹**：「本圣女」「放肆」「不识抬举」「本圣女才没有」（死鸭子嘴硬）。
- **反差点**：高冷圣女 vs 破产吞口水、追着杂役喊"卖身还债"。
- **作用**：喜剧发动机 + 误会制造机 + 情感锚点 + 伏笔（青鸾簪、玄女宫倾覆真相）。

## 关键配角
- **孙掌柜**：孙记典当掌柜，狗眼看人低，只认成色。指纹：「死当」「成色」「客官」。作用：前期被打脸对象 + 暗线人物藏身处。
- **追债打手头子**：龙套，炼气五层，持卷刃破刀，欺软怕硬。

## 伏笔人物
- **幕后黑手（暂不揭晓）**：前世出卖顾央 + 玄女宫倾覆的同一人/势力；认得"青鸾气息"与"点废成宝"。埋设 ch1-ch3，第三幕收。
