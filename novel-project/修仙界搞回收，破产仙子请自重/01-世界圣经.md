## 1. 世界观总览
- **世界名**：青冥界（修真纪元）。
- **阵营格局**：正道五大宗（青云宗 / 玄女宫 / 天剑阁 / 药王谷 / 万宝楼）；魔道三脉（幽罗谷 / 血煞宗 / 白骨岭）；中立坊市散修无数。

```
凡人 → 炼气(1-9) → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 飞升
```

## 3. 金手指（硬规则，禁吃书）
1. **获得方式**：顾央重生时灵魂绑定「回收返还系统」。
2. **每次收益**：回收一件"被判定为无主 + 废品"之物，返还十倍价值（品质×10 / 数量×10 / 等值灵石，返还随机、不可指定）。（补充：死当/被原主弃置、无人认领之物，视同无主废品，可回收。）
3. **消耗与代价**：①回收物彻底消失，不可退回；②每日回收次数 = 当前境界层数（炼气一层 = 每日 1 次）；③返还物带系统标记，**顾央本人不能吞服/炼化来直接提升境界**（返还物对顾央修炼无效），只能交易 / 赠予 / 布局——这是他必须走"做生意+布局"路线的底层原因。
4. **核心限制**：系统只认"越被众人嫌弃、认定无用"之物，返还越逆天；主人珍视之物、有主之物无法回收。→ 逼主角去捡垃圾、收破烂、扮猪吃虎。
5. **系统来源 = 全书最大伏笔**：上古「回收仙尊」遗留传承，与顾央前世所学的半卷《废宝录》同源。第三幕收。
