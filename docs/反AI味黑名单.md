# 反AI味黑名单 + 去AI味 SOP

> 用途：写完初稿，逐条对照自查。命中即修，不看感觉。
> 平台口径：番茄 = 白、快、爽。读者要代入感和爽点，不要文青金句、不要成语堆砌。
> 去AI味的目标不是"更像文学"，是"更像一个会讲故事的人在跟你唠"。

## 1. 套路词黑名单

### 1.1 高频AI腔虚词（密度阈值：每千字每类合计 ≤1 次）
- **副词系**：缓缓、微微、轻轻、淡淡、静静、深深、狠狠、紧紧、极
- **瞬发系**：顿时、瞬间、刹那、猛地、骤然、倏地
- **心理系**：心中一动、心中一凛、心中一沉、心中暗想、心头一颤
- **目光系**：目光一凝、眸光一闪、眼神一暗、眼底掠过一丝、眸中闪过、嘴角勾起一抹
- **神态系**：轻笑一声、冷哼一声、淡淡道、冷冷道、缓缓说道、沉声道、低声道、似笑非笑
- **虚比系**：仿佛、宛如、如同、好似、似乎、竟（滥用）、居然（滥用）

### 1.2 说教/总结句（0 容忍）
- "原来……才是……的真谛"
- "他终于明白……"
- "这一刻，他懂了……"
- "这，就是……" / "这就是……"
- "人生/修仙，不过是一场……"

### 1.3 空泛形容（删，换成具体动作/五感）
难以言喻、不可名状、莫名、某种、一股暖流/热流/寒意、深深地、莫名的、说不出的

### 1.4 翻译腔
正如……一般、在某种程度上、值得一提的是、值得注意的是、某种意义上、众所周知

### 1.5 机械排比
连续 ≥3 句相同结构的短句

### 1.6 被动滥用
"被……所……"、无主语的"被"连续出现

## 2. 六原则
1. **权力关系**：把"你需要/你应该/你必须"改成"我发现/说白了/我是这么"
2. **确定性**：纯结论处加犹豫痕迹——"我也不确定""至少在我这"
3. **废话**：说明书处插一句真实细节/题外话
4. **毛刺**：最完美的句子让它稍微不完整——加括号题外话、用"反正/说白了"
5. **偏心**：重要的多写、展开、加细节；其他的压缩一句话带过
6. **对称**：连续同构段落打破至少一个

## 3. 番茄风专项
- 易读性强
- 少破折号抒情、少"——"停顿腔
- 章末不要"金句升华"，要"钩子"
- 内心戏用主角第一视角吐槽，别用旁白总结
- 对话短、呛、带火气
- 使用肯定句。禁用【不是XX】，【没有XX】这样的否定句式

## 4. 执行 SOP
1. 初稿完成，按 §1 grep 自查，记录命中
2. 按 §2 六原则过一遍
3. 按 §3 番茄风过一遍
4. 批判编辑抽查 3 段，确认无残留
5. 说教句必须清 0；虚词类每千字超阈值必须压
