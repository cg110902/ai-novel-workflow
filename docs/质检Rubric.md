# 质检 Rubric（番茄口径 · 每章必过）

## 一、评分维度（每维 1–5 分）

| # | 维度 | 5 分标准 | 关键问句 |
|---|---|---|---|
| 1 | 钩子 | 开篇三句抓人；章末钩子让人想点下一章 | 前 100 字想继续看吗？最后一句想追吗？ |
| 2 | 爽点 | 本章 ≥1 个明确爽点（打脸/升级/收获/反转/信息差碾压） | 读者这一章爽在哪？ |
| 3 | 代入感 | 视角贴身、情绪真实、主角吐槽在场 | 读者能把自己当成主角吗？ |
| 4 | 去AI味 | 黑名单命中率达标、六原则合规、无文青金句 | 读起来像人类写的吗？ |
| 5 | 节奏 | 信息量足、废话率低、场景切换利落 | 有哪段想跳过去？ |
| 6 | 对话 | 删掉名字也能听出是谁在说话 | 这句谁说的？ |
| 7 | 一致性 | 与圣经/伏笔台账/人物卡零冲突 | 有没有吃书？ |
| 8 | 番茄口径 | 白、快、爽，完读率导向 | 番茄读者会划走吗？ |
| 9 | 动作表情 | 人物动作/表情/交互丰富、不重复、有道具与空间位置变化 | 有没有"看来看去"？ |
| 10 | 动作逻辑 | 每个动作符合场景：谁在场、能不能看见、有没有前因后果 | 这个动作在此时此地合理吗？ |
| 11 | 逻辑严密(不降智) | 主角赢靠信息差/规则/谋划，不靠运气或反派犯蠢 | 把反派换成聪明人，这章还成立吗？ |
| 12 | 因果自洽 | 每个反转有前因；力量体系不崩；铺垫有回收 | 这个反转，前面埋过线吗？ |

## 二、问题分级
- **S1 致命**：设定冲突 / 人设崩塌 / 主线矛盾 / 时间线错乱 → 必改
- **S2 严重**：无爽点 / 钩子弱 / 大段废话 / 说教句 → 应改
- **S3 建议**：个别 AI 味词 / 节奏小问题 / 细节瑕疵 → 建议改
- **S4 观察**：风格偏好 → 记录，不改

## 六、硬性词汇限制（每章仅限使用2次）
以下词汇在正文中每章仅限使用一次，对话/系统消息【】内无限制：
- **不是** → 替代：并非、算不上、不算
- **没有** → 替代：不见、缺失、寻不着
- **愣** → 替代：呆住、怔住、发呆

详见 `docs/词汇替换指南.md`

## 三、交付线
- 总分 ≥ 48/60（12 维 × 5 分）
- 且：无 S1；S2 ≤ 2；第 11、12 维任何一维 ≤ 2 分 = 视为 S2
- 不达标 → 定向重写 → 复评，直到达标

## 四、双盲的落地（诚实版）
1. **独立视角**：批判编辑的 prompt 只给「文本 + rubric + 圣经」，不给写手的意图与自评
2. **强制挑刺**：每章必须找出 ≥5 处问题
3. **隔章复看**：每写完 5 章，回头扫一次最早那章

## 五、批判编辑 Prompt 模板

```

【任务】
```
