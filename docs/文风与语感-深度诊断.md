# 文风与"别扭感"深度诊断 + 具体要求

> 2026-08-17 · 针对"人脑看着别扭"这一最难问题的系统拆解。
> 结论先行：**别扭感只有 20% 在词上，80% 在句子形状、段落镜头、和"解释/报道"的语用姿态上。**

## 一、别扭感的 5+1 层来源

### 第 1 层 · 词层（已解决，占比 20%）
禁用词、雷比喻、干巴复用词。

### 第 2 层 · 句层（已解决，占比 20%）
AI 的句子是"**完整闭合句**"——主谓宾齐全、长度整齐（都 15~25 字）。
人写的句子是"**残缺呼吸句**"——残句、零主语句、独词句，3 字到 60 字都有。
**判据**：碎短句占比、长句占比、句长方差、连续碎句段。

### 第 3 层 · 段层（已解决，占比 15%）
AI 的段落是"**总分总小作文**"——中心句→展开→小结。
网文的段落是"**镜头**"——一个动作/一句对话一段。

### 第 4 层 · 篇章层（**别扭感主来源，占比 40%**）
四个具体病灶：
| 病灶 | 表现 | 对策 |
|---|---|---|
| **解释** | AI 怕读者不懂，补逻辑 | 删连接解释，留白 |
| **报道** | AI 用旁观视角转述 | 贴人物五感写 |
| **命名情绪** | AI 直接说情绪名 | 写生理反应 |
| **上帝视角** | POV 跳出 | 锁死单 POV |

### 第 5 层 · 根本矛盾（不可消除）
生成模型的训练目标是"**预测最可能的下一个词**"= 统计平均 = 平庸安全。
好文笔的本质是"**在读者预期处，换一个更具体、更意外、更贴肉的一词**"。

### 第 6 层 · 动作层（新发现）
"别扭感"还有一个隐蔽来源：**人物动作、表情、交互单调，且不全符合逻辑**。
- 对策：
  1. 每千字视线词 ≤25，超过即"看来看去"
  2. 同一神态动作 ≥3 次即单调
  3. Rubric 加"动作表情""动作逻辑"两维

## 二、三件武器（治本）

### 武器 1 · 规则脚本
`novel_check.py` 抓第 1~4 层的机械问题。

### 武器 2 · 风格锚
`style_profiler.py` 把"语感"变成可测量的特征向量。使用 **番茄小说风格锚点**（`docs/番茄小说风格锚点.md`）作为参照标准，不依赖外部爆款。每章跑对比，偏离 >25% 的项就是返工目标。

### 武器 3 · 负样本库
重写时把"AI 味写法 vs 人味写法"成对喂给模型。

## 三、具体要求（数值化验收标准）

| 维度 | 硬性要求 |
|---|---|
| 字数 | 2000~2500 字/章 |
| 正文禁用词 | 0 命中 |
| 解释句/上帝视角/说教句 | 0 命中 |
| 副词 | ≤6/千字 |
| 连接词 | ≤3/千字 |
| 成语 | ≤2/千字 |
| "的"字 | ≤40/千字 |
| 比喻 | ≤4 处/章 |
| 句长 | 碎短句 15~45%，长句 ≥5% |
| 段落 | 一句一段 ≥30%，平均段长 ≤45 字 |
| 对话占比 | 30~60% |
| 章末钩子 | 末句须含悬念/危机/期待信号 |
| （正文禁【没有/不是】）（人物对话、人物内心戏除外） |
