# 番茄小说风格锚点

> 本项目的风格参照标准。番茄小说 = 白、快、爽，读者要代入感和爽点。

## 核心特征

### 句长分布
- 平均句长：12-20 字
- 碎短句（≤12字）：20-45%
- 长句（≥30字）：≥5%
- 避免全篇电报式短句，也避免文绉绉的长句

### 对话占比
- **30-60%**（推荐区间）
- 对话短促有力，带火气
- 删掉名字能听出是谁说的
- 每句台词不宜过长，越短越有张力

### 段落特征
- 平均段长：≤45 字
- 一句一段：30-50%
- 段末要动作/钩子，不要升华总结

## 词汇密度

| 指标 | 参考值 |
|------|--------|
| 副词 | 越少越好 |
| 连接词 | 越少越好 |
| 成语 | ≤2/千字 |
| "的"字 | ≤40/千字 |

## AI 味特征（避坑）

### 禁用词（正文每章限用2次）
- **不是** → 替代：并非、算不上
- **没有** → 替代：不见、缺失
- **愣** → 替代：呆住、怔住

### 高频AI腔（禁用/少用）
- **副词**：缓缓、微微、轻轻、淡淡、静静、深深、狠狠、顿时、瞬间、刹那、猛地、骤然
- **目光系**：目光一凝、眸光一闪、眼底掠过、嘴角勾起
- **神态系**：轻笑一声、冷哼一声、淡淡道、沉声道
- **心理系**：心中一动、心中一凛、心中暗想

### 说教/解释句（禁）
- "原来……才是……的真谛"
- "这一刻，他懂了……"
- "这说明……"
- "也就是说……"
- "人生不过是一场……"

### 空泛形容（禁）
难以言喻、不可名状、莫名、某种、一股暖流/热流/寒意

## 番茄风专项要求

### 去解释原则
- **禁止解释句**：不要解释"为什么"，让读者自己理解
- **禁止命名情绪**：不写"他很紧张"，写"他手心出汗"
- **禁止上帝视角**：不写"殊不知危险正在逼近"
- **禁止总结句**：段末不写"这就是……"

### 动作逻辑要求
每个动作必须符合：
1. **谁在场**：在场的人才能看到/反应
2. **合不合理**：坐着的人不能突然站起来，除非有原因
3. **有前因后果**：动作要有铺垫，不能凭空出现

### 情绪表达
- 用**生理反应**替代情绪命名
- 用**具体动作**替代抽象描写
- "手心出汗"替代"紧张"
- "后槽牙咬紧"替代"愤怒"

### 章末要求
- 要**钩子**（？/！/……）
- 不要**升华金句**
- 留悬念让读者想点下一章

## 使用方式

每章写完后跑 `style_profiler.py` 对比指标，偏离 >25% 的项重点检查。

```bash
python3 scripts/style_profiler.py 锚点文本.md 待检章节.md
```
