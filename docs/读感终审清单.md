# 读感终审清单（终审依据 · 读感第一）

> **终审 = 用户负责。** 本清单是终审的检查依据，两级都用：
> - **Agent 交付前**：按清单自检预审，把能修的先修掉；
> - **用户终审**：按同一份清单挑问题，说哪里不过，Agent 定向重写。
> 任何一条不过 → 定向重写，不看脚本分数。
> 心法：忘掉所有数值。假装自己是读者，从头读到尾，只问一件事——"爽不爽 / 顺不顺 / 想不想往下看"。

## 一、默读测试（最重的一条）
1. 逐句默读一遍，哪里有"卡一下"的地方？（拗口、重复、语义打架）
2. 有没有一句话要读两遍才懂？
3. 删掉任意一句，读者会损失什么？如果毫无损失 → 删。

## 二、梗/比喻的密度控制
1. 适当控制比喻密度，不能太高。

## 三、情绪到位
1. 该紧张的地方，心提起来了吗？
2. 该爽的地方，爽到了吗？（打脸 / 升级 / 收获 / 反转 / 信息差碾压）
3. 该好笑的地方，笑了吗？（没笑 = 梗废了，重写）

## 四、人物角色动作/交互/表情符合逻辑
1. 每个动作，符合"此时此地此人"吗？（谁在场、能不能看见、前因后果）
2. 有没有"看来看去"？同类动作连着三次 → 换。
3. 主角/反派的每个决定，聪明吗？（把反派换成聪明人，剧情还成立吗？）
4. 人物表情动作是否符合逻辑？是不是就只知道"笑"？
5. 人物角色动作/交互/表情是否过于单一？来来去去老是那几个？

## 五、章末
1. 读完最后一句，想点下一章吗？
2. 章末是"钩子"还是"金句"？（要钩子，不要升华）

## 六、声音
1. 每句台词，删掉名字，能听出是谁说的吗？
2. 主角的吐槽/口吻，这一章还在吗？（不能写着写着变回旁白）

## 七、克制
1. 有没有"生怕读者不懂"而多写的解释句？
2. 有没有情绪被"命名"而不是被"演出来"？
3. 该留白的地方，留白了吗？

> 判读原则：脚本的"△偏出"只决定"这里要多看一眼"；本清单的"不过"才决定"返工"。两者不要混。
