# 词汇替换指南

> 【硬性限制】以下词汇每章仅限使用2次（人物对话除外）：
> - **不是** 
> - **没有** 
> - **笑** 
> - **愣** 

## 替代示例

| 原词 | 替代方案 |
|------|----------|
| "这不是" | "这并非"、"这算不上" |
| "没有钱" | "囊中羞涩"、"身无分文" |
| "愣住了" | "怔在原地"、"呆住了" |
| "眼皮一跳" | "眼皮一跳"已禁用，改为"心下一惊" |

## 使用原则

1. **每章每词最多2次**（正文部分）
2. **对话部分无限制**
3. **系统消息【】内无限制**
4. **尽量用动作/表情替代抽象描述**
